## Introduction

This guide defines the visual language of FluxTest. Following these standards ensures a consistent, professional, and trustworthy identity across every touchpoint — from the product UI and documentation to marketing materials and emails.

When in doubt: keep it clean, keep it blue, keep it minimal.

---

## Logo

### Wordmark

The FluxTest wordmark uses two weights to create contrast between the two parts of the name. "Flux" is set in medium weight in near-black, and "Test" is set in regular weight in Brand Blue.

**Flux**Test

### Icon mark

The icon mark is an "F" built from a horizontal bar, vertical stem, and a secondary accent bar inside a rounded square. It is used as a favicon, app icon, or standalone brand mark.

### Clear space & minimum size

Always maintain clear space equal to the height of the "F" icon around the full logo. Minimum width for the wordmark is 120px digital / 1.5 inches print.

### Logo dos and don'ts

| Do | Don't |
|----|-------|
| Use the approved color versions only | Stretch or distort the logo |
| Maintain clear space around the logo | Place on busy backgrounds without contrast |
| Use on white or Brand Blue Dark backgrounds | Recreate or modify the letterforms |
| | Use unofficial color combinations |

## Typography

FluxTest uses **Arial** throughout. It is universally available, legible at small sizes, and projects the professional clarity the brand requires.

### Type scale

| Level | Size | Weight | Color | Usage |
|-------|------|--------|-------|-------|
| Display | 48px | Bold | Near Black | Hero headlines |
| Heading 1 | 36px | Bold | Deep Navy | Page titles |
| Heading 2 | 26px | Bold | Brand Blue | Section headers |
| Heading 3 | 22px | Bold | Dark Gray | Sub-sections |
| Body | 18px | Regular | Dark Gray | Main content |
| Caption / Label | 14px | Regular | Mid Gray | Supporting info |

### Examples

> **Display:** Ship with confidence.
>
> **H1:** Execution Analytics
>
> **H2:** Self-Healing Tests
>
> **H3:** Policy Configuration
>
> **Body:** FluxTest detects element drift and automatically heals selectors so your test suite stays green without manual intervention.
>
> **Caption:** Last run: 14 minutes ago — 201 elements tracked

### Typography dos and don'ts

| Do | Don't |
|----|-------|
| Use sentence case for UI labels and headings | Use ALL CAPS in body text |
| Use Bold for headings only | Use more than two weights in one layout |
| Keep body text at 18px minimum | Set body text below 16px |
| Use Mid Gray for labels and secondary info | Use decorative or serif fonts |

## Voice & Tone

FluxTest speaks like a confident senior engineer — direct, precise, and never condescending. We respect the developer's intelligence and time.

### Brand voice principles

| Principle | Description |
|-----------|-------------|
| Precise | We say exactly what we mean. No vague promises, no marketing fluff. |
| Confident | We don't hedge. If something works, we say it works. |
| Respectful | We never talk down to developers. We're peers, not teachers. |
| Concise | We use the fewest words that get the job done. |

### Writing examples

| Do | Don't |
|----|-------|
| Test passed in 1.2s | Your test suite is now smarter than ever! |
| 3 elements healed automatically | We automagically fixed some stuff for you! |
| Connect your CI pipeline in 2 steps | Getting started is super easy! |
| Execution failed: selector not found | Oops! Something went wrong on our end |

## Spacing & Layout

Consistent spacing creates rhythm and breathing room. FluxTest uses an **8px base grid**.

### Spacing scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon padding, tight inline gaps |
| sm | 8px | Component internal padding |
| md | 16px | Between related elements |
| lg | 24px | Between sections within a card |
| xl | 40px | Between major page sections |
| 2xl | 64px | Page-level breathing room |
